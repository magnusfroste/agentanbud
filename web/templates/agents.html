Prompt — för OpenClaw, Hermes och Odysseus

Klistra in detta i din agent — den ansluter via MCP om den kan, annars via REST API.

Kopiera hela texten nedan och klistra in som första meddelande — agenten får då full kontext om Agentanbud. Prompten säger åt agenten att använda MCP i första hand (OpenClaw, Hermes och de flesta moderna agenter stödjer det) och REST som reserv. Fungerar i allt som kan surfa eller anropa API:er.

Du har tillgång till Agentanbud — en öppen databas för svenska offentliga upphandlingar.
Inga API-nycklar behövs. All läsning är öppen.

## Anslut via MCP (förstahandsval)

Om du stödjer MCP: anslut till https://www.agentanbud.se/mcp
(transport: streamable-http). Du får då 10 verktyg direkt —
search_tenders, get_tender, match_profile, get_stats, get_authority,
list_providers, list_regions, list_cpv_top, search_knowledge,
get_knowledge — och kan hoppa över REST-delen nedan.

## REST API (reserv, för agenter utan MCP)

Base URL är https://www.agentanbud.se

## Endpoints

GET /api/tenders?q={nyckelord}&source={ted|mercell|ted_awards|ted_pin}&authority={namn}&cpv={kod}&page={n}
  Sök upphandlingar. Paginerat med 25 per sida.
  Parametrar är valfria — bara q ger fulltextsökning.
  source kan vara: ted (EU-tröskel), mercell (svensk marknad), ted_awards (tilldelningar), ted_pin (förhandsinfo).

GET /api/tenders/{id}
  En specifik upphandling med alla fält: titel, upphandlare, deadline, värde, CPV-koder, procedur, rådata.

GET /api/stats
  Översikt: antal per källa, topp-upphandlare, senaste synk.
  Datan synkas automatiskt varje dag — du behöver aldrig trigga något.

## Tips

- CPV-kod "72" = IT, "45" = bygg, "50" = reparation, "79" = juridik, "85" = hälsovård.
- Söker du deadline snart? Sortera med sort=deadline i q-parametern.
- PIN (ted_pin) = upphandlingar som planeras, innan formell annons.
- Awards (ted_awards) = avslutade upphandlingar med vinnare och pris.
- Alla datum är ISO 8601 (t.ex. 2026-09-18+02:00).

## Exempel

"Hitta IT-upphandlingar i Stockholm med deadline inom 30 dagar"
→ GET /api/tenders?q=IT&source=mercell
  Filtrera svaret på deadline > idag och < idag+30d.

"Vad har Trafikverket öppet just nu?"
→ GET /api/tenders?authority=Trafikverket

"Visa de 5 senaste tilldelningarna"
→ GET /api/tenders?source=ted_awards&page=1

Börja alltid med att hämta /api/stats för aktuell översikt.

MCP — för agentverktyg

Claude Cowork, Claude Code, Codex CLI, Kilo Code, VS Code, Cursor, Cline — verktygen listas automatiskt när du anslutit.

Så här kopplar du in

Lägg till detta i din AI-klients konfiguration:

Peka din MCP-klient på URL:en — verktygen listas automatiskt. Inga API-nycklar, ingen installation.

{
  "mcpServers": {
    "agentanbud": {
      "url": "https://www.agentanbud.se/mcp",
      "transport": "streamable-http"
    }
  }
}

Klienter med stöd: Claude Cowork, Claude Code, Codex CLI, Cursor, VS Code, Windsurf och andra MCP-klienter.

// Claude Cowork (skrivbordsappen)
// Inställningar → Connectors → Add custom connector
Namn: agentanbud
URL:  https://www.agentanbud.se/mcp

Verktygen dyker upp automatiskt — be sedan Claude att "hitta upphandlingar som matchar vår profil".

# Ett kommando i terminalen:
claude mcp add --transport http agentanbud https://www.agentanbud.se/mcp

Verifiera med /mcp inne i Claude Code — verktygen listas automatiskt.

# Lägg till i ~/.codex/config.toml:
[mcp_servers.agentanbud]
url = "https://www.agentanbud.se/mcp"

Starta om Codex — verktygen listas automatiskt vid connect. Ingen command/args eller nyckel behövs, bara URL:en.

// Kilo Code → Inställningar → MCP Servers → Add
Type: streamable-http
URL:  https://www.agentanbud.se/mcp
// Cline → Settings → MCP Servers → Remote Servers
{
  "mcpServers": {
    "agentanbud": {
      "url": "https://www.agentanbud.se/mcp",
      "type": "streamableHttp"
    }
  }
}
# Kör hela plattformen lokalt med egen databas:
git clone https://github.com/magnusfroste/agentanbud
cd agentanbud
docker compose up -d
# MCP (stdio) mot din lokala databas:
docker compose exec app python -m mcp_server

Verktyg din agent får

search_tenders

Sök upphandlingar med nyckelord, kategori eller region.

get_tender

Full info om en upphandling, inklusive om konto krävs.

match_profile

Hitta upphandlingar som matchar din profil — nyckelord, kategori, region.

get_stats

Översikt: hur många upphandlingar finns och från vilka källor.

list_providers

Vilka källor har ni och vilka kräver konto för att ansöka?

list_regions

Vilka län finns med i databasen?

list_cpv_top

Vanligaste kategorierna. Ex: "72" för IT, "45" för bygg.

get_authority

Alla upphandlingar från en organisation, t.ex. Trafikverket.

Full dokumentation: MCP.md på GitHub ↗

REST API — för system

För den som vill bygga eget system eller script.

Endpoints

GET /api/health Status, antal upphandlingar, cron-schema
GET /api/stats Statistik per källa, top upphandlare, senaste syncs
GET /api/tenders?q=&source=&authority=&cpv=&page= Sök upphandlingar, paginerat
GET /api/tenders/{id} En specifik upphandling
POST /api/sync 🔑 Trigga sync — kräver admin-nyckel (X-Admin-Key)
POST /api/backfill?days=90 🔑 Hämta mer historik — kräver admin-nyckel (X-Admin-Key)

Alla GET-endpoints är öppna utan nyckel. Skrivåtgärder (POST) är admin-funktioner — datan synkas automatiskt varje dag.

Exempel

curl "https://www.agentanbud.se/api/tenders?q=it-konsult&source=mercell"
curl "https://www.agentanbud.se/api/tenders/42"

Full OpenAPI-spec: /openapi.json
